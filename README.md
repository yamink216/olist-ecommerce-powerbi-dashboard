# Olist E-Commerce Analytics Dashboard

## Project Overview
An interactive Business Intelligence dashboard built using Microsoft Power BI to analyze the Olist Brazilian E-Commerce marketplace.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

## Key Features
- Data cleaning and transformation across 9 tables
- Data modeling and relationship creation
- 8 DAX KPI measures
- Interactive date, customer state and order status filters
- Sales, customer, product, seller and payment analysis

## Key Performance Indicators
- Total Sales
- Total Orders
- Total Customers
- Average Order Value
- Total Products Sold
- Total Sellers
- Average Review Score
- Total Freight Cost

## Dashboard Visualizations
- Monthly Sales Trend
- Sales by Product Category
- Top 10 Best-Selling Products
- Orders by Customer State
- Payment Type Analysis
- Monthly Orders Trend
- Order Status Analysis
- Sales by Brazilian State

Olist Brazilian E-Commerce Public Dataset:
